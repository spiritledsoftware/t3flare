Tools

Preset

How each tool reaches the model: direct (in every request), deferred (loaded by tool_search; scripts call it any time), codemode (code mode's scripts only) or hidden. An extension runs while any of its tools is not hidden: hiding codemode turns code mode off, hiding web_search turns searching off. A preset sets every tool that is not hidden at once, t3's and MCP servers' included, except an MCP server's code-mode-only tools (core: direct, MCP servers' deferred; codemode-only: deferred; everything: direct). A change saves at once and applies at each thread's next turn. MCP servers' tools, t3's included, are set on their cards.
